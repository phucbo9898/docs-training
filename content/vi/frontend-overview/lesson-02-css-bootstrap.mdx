## 🎯 Mục tiêu

- Hiểu CSS dùng để làm gì
- Biết selector + box model + layout cơ bản
- Biết cách tổ chức CSS file
- Dùng Bootstrap để dựng layout/UI nhanh

## 1) CSS là gì?

CSS dùng để **style giao diện** cho HTML. File CSS thường có đuôi `.css`.

## 2) Cấu trúc CSS

```css
selector {
	property: value;
}
```

## 3) Selector cơ bản

```css
/* tag */
p { color: red; }

/* class */
.box { background: blue; }

/* id */
#header { font-size: 20px; }
```

## 4) Cách chèn CSS

### External (khuyến nghị)

```html
<link rel="stylesheet" href="style.css" />
```

### Internal

```html
<style>
	p { color: red; }
</style>
```

### Inline (hạn chế dùng)

```html
<p style="color: red;">Hello</p>
```

## 5) Box model (cốt lõi)

- margin, border, padding, content

## 6) Layout nhanh với Flexbox (khuyến nghị)

```css
.container {
	display: flex;
	gap: 12px;
}
```

## 7) Bootstrap (giới thiệu)

Bootstrap là CSS framework giúp dựng UI nhanh bằng hệ thống grid + utility classes + components.

### Cài đặt (CDN)

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet" />
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

### Grid cơ bản

```html
<div class="container">
	<div class="row">
		<div class="col-12 col-md-6">Left</div>
		<div class="col-12 col-md-6">Right</div>
	</div>
</div>
```

### Component ví dụ (Button)

```html
<button class="btn btn-primary">Save</button>
```
