## 🎯 Mục tiêu khóa học

- Nắm nền tảng HTML để dựng cấu trúc trang web
- Biết CSS để layout + styling, và dùng Bootstrap để làm UI nhanh
- Nắm JavaScript cơ bản: DOM, event, function, array/object
- Biết jQuery để thao tác DOM và Ajax nhanh
- Gọi API và render data lên UI (AJAX / fetch)
- Hiểu quy trình ghép Frontend ↔ Backend (form submit, validate, call API)

## 👥 Đối tượng

- Thực tập sinh / Fresher mới bắt đầu Frontend
- Có máy cá nhân và có thể tự chạy project local

## ✅ Yêu cầu trước khi học

- Editor: VS Code
- Trình duyệt: Chrome/Edge (khuyến nghị)
- Biết Git cơ bản là lợi thế

## 📝 Quy ước thực hành

- Mỗi lesson tạo 1 folder riêng (ví dụ: `lesson-01-html/`, `lesson-02-css/`…)
- Luôn tách file: `index.html`, `style.css`, `app.js` (không viết hết inline)
- Tên class theo hướng BEM hoặc theo quy ước team (ưu tiên rõ nghĩa)
