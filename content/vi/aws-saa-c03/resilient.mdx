Domain này hỏi: hệ thống có sống sót khi một phần hỏng không, và có tách rời được các thành phần không. Tỉ lệ đúng ở Đề 4: **47%**, ưu tiên ôn số 2.

## 4 chiến lược DR

Đề hay hỏi theo RPO/RTO và chi phí.

| Chiến lược | Ở region DR có gì | RTO | Chi phí |
| --- | --- | --- | --- |
| **Backup & Restore** | Chỉ có <mark>backup/snapshot</mark> | Hàng giờ | <mark>Rẻ nhất</mark> |
| **Pilot Light** | <mark>DB replicate sẵn</mark>, <mark>server tắt</mark> | Hàng chục phút | Thấp |
| **Warm Standby** | <mark>Bản thu nhỏ chạy sẵn</mark>, scale khi cần | Vài phút | Trung bình |
| **Multi-site Active-Active** | <mark>Bản đầy đủ chạy song song</mark> | <mark>Gần 0</mark> | Đắt nhất |

## Keyword theo tình huống

| Thấy trong đề | Chọn |
| --- | --- |
| Scale web app, thêm <mark>elasticity</mark> | **ELB + Auto Scaling Group** trải nhiều AZ (hoặc Route 53 Weighted cho nhiều EC2) |
| Cần <mark>tối thiểu N instance</mark> khi <mark>1 AZ sập</mark> | **Tổng − AZ lớn nhất ≥ N**; rẻ nhất mỗi AZ = N / (số AZ − 1). Ví dụ 6 instance, 3 AZ → 3-3-3 |
| RDS phải sống khi <mark>AZ sập</mark>, <mark>failover tự động</mark> | **RDS Multi-AZ** (sync, failover 60–120 giây, đổi CNAME) |
| Aurora <mark>failover nhanh</mark>, <mark>không đổi endpoint</mark> | Thêm **Aurora Replica** (reader) cùng cluster; app ghi qua Cluster endpoint |
| DR <mark>cross-region</mark>, <mark>RPO ~1 giây</mark>, RTO &lt; 1 phút | **Aurora Global Database** |
| <mark>NoSQL toàn cầu</mark>, low latency, <mark>nhiều region</mark> | **DynamoDB Global Tables** |
| NAT Gateway không là <mark>single point of failure</mark> | **1 NAT Gateway mỗi AZ**, private subnet trỏ NAT cùng AZ |
| <mark>Trang dự phòng</mark> khi app sập | **Route 53 Failover routing → S3 static website** |
| Chỉ sang region phụ <mark>khi region chính lỗi</mark> | **Route 53 Failover routing** + health check |
| <mark>Tất cả site cùng chạy</mark> | **Route 53 Active-Active** + health check |
| <mark>Region sập</mark>, <mark>downtime thấp nhất</mark> | **Resource chạy sẵn ở region 2 + Route 53 failover** (restore snapshot mất hàng giờ) |
| CloudFront lỗi 5xx, <mark>tự chuyển origin</mark> | **CloudFront origin group** (origin failover) |
| <mark>Backup Direct Connect</mark> | **DX thứ 2**, hoặc **Site-to-Site VPN** |
| <mark>Request bị mất</mark> khi <mark>tải đột biến</mark> | **Đệm bằng SQS**, ASG scale theo backlog |
| <mark>Decouple</mark>, xử lý <mark>bất đồng bộ</mark> | **SQS** (pull) |
| <mark>Exactly-once</mark>, <mark>đúng thứ tự</mark> | **SQS FIFO** |
| <mark>Message lỗi lặp lại</mark> làm nghẽn queue | **Dead-letter queue** + maxReceiveCount |
| 1 event gửi tới nhiều nơi (<mark>fan-out</mark>) | **SNS topic → nhiều SQS**; hoặc **EventBridge** |
| <mark>Lọc message</mark> vào từng queue | **SNS subscription filter policy** |
| <mark>Ưu tiên premium/free</mark> | **2 SQS queue**, poll queue ưu tiên trước (SQS không có priority) |
| Bắt <mark>thay đổi item DynamoDB</mark> | **DynamoDB Streams + Lambda** |
| Bắt <mark>thay đổi dữ liệu Aurora MySQL</mark> | **Aurora native function gọi Lambda** (RDS event subscription chỉ báo sự kiện instance) |
| Chạy <mark>ECS task</mark> khi có <mark>file mới trên S3</mark> | **EventBridge rule → ECS task** (không cần Lambda) |
| <mark>Workflow nhiều bước</mark>, retry, <mark>chờ duyệt</mark> | **Step Functions** |
| Migrate <mark>ActiveMQ/RabbitMQ</mark> | **Amazon MQ** |
| <mark>Chờ app cài xong</mark> mới tạo resource tiếp (CloudFormation) | **CreationPolicy + cfn-signal** (DependsOn chỉ ép thứ tự) |
| <mark>Đổi AMI cho ASG</mark> | **Launch template version mới + Instance Refresh** |
| <mark>ASG scale-in</mark> terminate instance nào | **AZ nhiều instance nhất → launch template cũ nhất → gần giờ billing** |
| <mark>Session bị mất</mark> khi instance bị terminate | Lưu session ra **ElastiCache** hoặc **DynamoDB** (sticky sessions vẫn mất khi instance chết) |
| <mark>Backup tập trung</mark> nhiều service, <mark>> 35 ngày</mark>, <mark>cross-account</mark> | **AWS Backup** (DLM chỉ cho EBS) |
| <mark>Chống xóa nhầm</mark> object S3 | **Versioning + MFA Delete** |
| S3 sống sót khi <mark>region sập</mark> | **Cross-Region Replication** (cần Versioning) |
| <mark>Redshift DR</mark> khi region sập | **Cross-Region Snapshot Copy** |
