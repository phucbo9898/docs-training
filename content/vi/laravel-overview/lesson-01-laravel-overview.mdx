## 🎯 Mục tiêu bài học

- Hiểu Laravel là gì
- Biết Laravel dùng để làm gì
- Hiểu mô hình MVC trong Laravel
- Nắm được lợi ích khi dùng Laravel thay vì PHP thuần

## 📖 1. Laravel là gì?

- Laravel là một framework PHP mã nguồn mở, được phát triển bởi Taylor Otwell.
- Laravel giúp xây dựng ứng dụng web theo mô hình MVC (Model - View - Controller).
- Laravel cung cấp sẵn nhiều chức năng:
  - Routing
  - Authentication
  - Database ORM (Eloquent)
  - Middleware
  - Queue, Cache, API,...
- Mục tiêu: giúp dev code nhanh hơn, sạch hơn, dễ maintain hơn.

## 🤔 2. So sánh Laravel và PHP thuần?

PHP thuần vs Laravel

- Code: Laravel clean hơn
- Tốc độ dev: Laravel nhanh hơn
- Structure: Laravel rõ ràng
- Bảo trì: Laravel dễ hơn

👉 Kết luận:

- Laravel giúp tiết kiệm thời gian và giảm bug.

## 🧠 3. Mô hình MVC là gì?

👉 Đây là phần quan trọng nhất của bài

MVC = Model - View - Controller

1. Model
   - Xử lý dữ liệu
   - Làm việc với database
2. View
   - Giao diện người dùng (HTML, Blade)
3. Controller
   - Nhận request
   - Xử lý logic
   - Trả về response

👉 Flow:

- User → Route → Controller → Model → Controller → View → User

Ví dụ: Xem danh sách bài viết

1. User truy cập URL: /posts
2. Route gọi đến PostController
3. Controller gọi Model (Post) để lấy data
4. Model query database
5. Controller trả data về View
6. View hiển thị danh sách bài viết

👉 Đây chính là flow chuẩn của Laravel
