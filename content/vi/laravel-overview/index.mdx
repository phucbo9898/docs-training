## 🎯 1. Mục tiêu khóa học

- Hiểu được Laravel framework và cách hoạt động theo mô hình MVC
- Nắm được cấu trúc project Laravel
- Biết cách làm việc với Routing, Middleware, Model
- Thao tác database với Migration, Seeder, Eloquent ORM
- Có khả năng build API/Web cơ bản bằng Laravel

## 🗺️ 2. Learning Path (Lộ trình học)

- Hiểu Laravel là gì
- Setup môi trường & chạy project
- Hiểu cấu trúc project
- Làm việc với HTTP (Controller, Middleware, Request)
- Làm việc với Database (Migration, Seeder)
- Query dữ liệu bằng Eloquent ORM

## 🛠️ 3. Yêu cầu môi trường (Requirements)

- PHP >= 8.2
- Composer
- XAMPP / Laragon
- MySQL
- VS Code / PHPStorm

## 📌 4. Quy tắc training (Training Rules)

- Mỗi lesson phải đọc + thực hành
- Sau mỗi lesson có bài tập nhỏ
- Không copy code, phải hiểu logic
- Review code với mentor

## 🎯 5. Output sau training

- Tự build được CRUD API bằng Laravel
- Hiểu flow request → controller → model → response
