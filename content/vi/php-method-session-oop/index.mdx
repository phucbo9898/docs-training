## 🛠️ PHP Method (Phương thức trong Class)

### Magic Methods (\_\_construct, \_\_destruct)

Tự động chạy khi khởi tạo hoặc hủy đối tượng.

```php
class MyClass
{
    protected $name;
    
    public function __construct()
    {
        $this->name = "Example constructor";
    }

    public function __destruct()
    {
        $this->name = "Example __destruct";
    }
}
```

### Static Method

Có thể gọi trực tiếp từ tên Class mà không cần tạo đối tượng của class

```php
class Car {
    public function __construct(public $brand) {} // Constructor Promotion

    public static function categories() {
        return ['Sedan', 'SUV', 'Truck'];
    }
}

// Gọi Static Method
$types = Car::categories();
```

### Phương thức có tham số

Phương thức có thể nhận các tham số và trả về giá trị.

```php
class Calculator
{
    public function sum($a, $b)
    {
        return $a + $b;
    }
}

$calculator = new Calculator();
$result = $calculator->sum(5, 10);
echo "The sum is: " . $result;
```

### Phương thức kế thừa (Inheritance)

Một lớp có thể kế thừa các phương thức từ lớp khác.

```php
class ParentClass
{
    public function parentMethod()
    {
        return "Hello from the parent class!";
    }
}

class ChildClass extends ParentClass
{
    public function childMethod()
    {
        return "Hello from the child class!";
    }
}

$child = new ChildClass();
echo $child->parentMethod() . "\n";
echo $child->childMethod() . "\n";
```

### Phương thức HTTP

Trong PHP, các phương thức HTTP như **GET**, **POST**, **PUT**, **DELETE**, và **PATCH** được sử dụng để chỉ định các hành động mà server cần thực hiện khi nhận được một yêu cầu (request) từ client.

| Phương thức                                                                       | Mô tả                                                                                                       |
| --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| GET                                                                               | Gửi dữ liệu dưới dạng chuỗi truy vấn được gắn vào URL.                                                      |
| Nó thường được sử dụng cho các yêu cầu không nhạy cảm hoặc không yêu cầu bảo mật. |                                                                                                             |
| POST                                                                              | Gửi dữ liệu trong phần thân của yêu cầu HTTP.                                                               |
| Nó thường được sử dụng cho các yêu cầu nhạy cảm hoặc khi gửi dữ liệu lớn.         |                                                                                                             |
| PUT                                                                               | Dữ liệu được gửi trong thân của yêu cầu (giống **POST**), thường dùng để **cập nhật hoàn toàn** tài nguyên. |
| Nếu tài nguyên không tồn tại, PUT có thể tạo mới tài nguyên đó.                   |                                                                                                             |
| PATCH                                                                             | Khác với **PUT**, **PATCH** chỉ cập nhật một **phần** của tài nguyên, thay vì toàn bộ tài nguyên.           |
| DELETE                                                                            | Yêu cầu này sẽ xóa tài nguyên được chỉ định.                                                                |

## **Superglobals trong PHP**

- Được hiểu là các biến số được dựng sẵn trong PHP
- Có thể sử dụng ở mọi nơi trong 1 script PHP
- Bao gồm

| $\_GLOBALS | Biến này chứa tham chiếu đến tất cả các biến toàn cục trong tập lệnh PHP hiện tại.                                      |
| ---------- | ----------------------------------------------------------------------------------------------------------------------- |
| $\_FILES   | Chứa thông tin khi người dùng upload file (tên file, kích thước, loại file).                                            |
| $\_COOKIE  | Dữ liệu lưu trên máy người dùng.                                                                                        |
| $\_SERVER  | Lưu trữ thông tin header, đường dẫn, vị trí script PHP                                                                  |
| $\_SESSION | Dữ liệu lưu trên Server (biến mất khi đóng trình duyệt hoặc hết hạn).                                                   |
| $\_GET     | Dùng để lấy các dữ liệu của một form sau khi được submit thông qua phương thức GET hoặc lấy dữ liệu được truyền qua URL |
| $\_POST    | Dùng để lấy các dữ liệu của một form sau khi được submit thông qua phương thức POST                                     |
| $\_REQUEST | Chứa dữ liệu của cả `$_GET`, `$_POST` và `$_COOKIE`. (Hạn chế dùng vì lý do bảo mật và tính minh bạch của code)         |
| $\_ENV     | Chứa các biến môi trường của hệ thống.                                                                                  |

- Lưu ý khi sử dụng
  - **Tránh dùng $\_REQUEST:**
    - Nếu bạn đợi dữ liệu từ Form POST, hãy dùng `$_POST`.
    - Điều này giúp bạn kiểm soát được luồng dữ liệu và tránh bị tấn công "Request Hijacking".

## 🍪 Session & Cookie

Đây là cách để ứng dụng web "nhớ" được người dùng giữa các lần chuyển trang.

- **Cookie:** Lưu tại **Trình duyệt** của người dùng (dễ bị can thiệp, dùng cho dữ liệu không nhạy cảm như tùy chọn ngôn ngữ).
- **Session:** Lưu tại **Server** (an toàn hơn, dùng cho đăng nhập, giỏ hàng).

## 🏗️ 4 Tính chất của OOP (Cực kỳ quan trọng)

Đây sẽ là nền tảng để hiểu cách Laravel hoạt động

### OOP là gì?

- OOP là viết tắt của Lập trình Hướng đối tượng. OOP được sinh ra để giải quyết những vấn đề mà lập trình truyền thống gặp phải.
- Lập trình Hướng đối tượng không chỉ là cú pháp, lệnh mới mà còn là một cách suy nghĩ mới khi giải quyết vấn đề.

### Thuật ngữ chính trong OOP

![Minh họa lớp và đối tượng: bên trái là lớp Car vẽ bằng nét đứt như một bản thiết kế, bên phải là ba đối tượng cụ thể tạo từ lớp đó gồm Audi, Nissan và Volvo](/content-images/php-method-session-oop/image.png)

- Lớp (class) là một định nghĩa chung cho một đối tượng.

  - Để dễ hình dung, bạn có thể nghĩ về lớp như một bản thiết kế trong khi đối tượng là một triển khai cụ thể của bản thiết kế đó.

  👉 Lớp (class) có thể hiểu như 1 mẫu

- Đối tượng (object) là một thực thể cụ thể dựa trên mẫu

### Các thuộc tính trong OOP

#### Tính đóng gói

- Được hiểu là việc giới hạn quyền truy cập (hoặc thay đổi) giá trị của thuộc tính hoặc quyền gọi phương thức
- Được sử dụng thông qua các từ khóa
  - **public**: có thể truy cập từ bất kỳ đâu
  - **private:** chỉ cho phép truy cập (thay đổi) ở phạm vi của class đó
  - **protected**: chỉ có thể truy cập bên trong lớp và các lớp kế thừa từ lớp đó
- Ví dụ minh họa

```php
class Fruit
{
    public $name;
    protected $color;
    private $weight;
}

$lemon = new Fruit();
$lemon->name = "Lemon"; // OK
$lemon->color = "Yellow"; // ERROR: Không thể truy cập thuộc tính protected ở bên ngoài lớp
$lemon->weight = 0.2; // ERROR: Không thể truy cập thuộc tính private ở bên ngoài lớp
```

#### Tính kế thừa

- Đây là tính chất được sử dụng khá nhiều. Tính kế thừa cho phép xây dựng một lớp mới (lớp Con), kế thừa và tái sử dụng các thuộc tính phương thức dựa trên lớp cũ (lớp Cha) đã có trước đó.
- Các lớp Con kế thừa toàn bộ thành phần của lớp cha và không cần phải đinh nghĩa lại. Lớp có thể mở rộng các thành phần kế thừa hoặc bổ sung những thanh phần mới

```php
class Animal
{
    protected $name;
    public function __construct($name)
    {
        $this->name = $name;
    }

    public function eat()
    {
        return $this->name . " is eating.";
    }

    public function sleep()
    {
        return $this->name . " is sleeping.";
    }
}

class Dog extends Animal
{
    private $weight;
    public function bark()
    {
        return $this->name . " is barking.";
    }
}

$dog = new Dog('dog');
$dog->eat();
$dog->sleep();
$dog->bark();
```

#### Tính đa hình

- "Đa hình" nghĩa là "nhiều hình thái".
- Các đối tượng khác nhau có thể thực hiện cùng một hành động theo những cách khác nhau.

```php
interface Player
{
    public function play();
}

class MusicPlayer implements Player
{
    public function play()
    {
        return "Đang phát nhạc MP3...";
    }
}

class VideoPlayer implements Player
{
    public function play()
    {
        return "Đang chiếu phim MP4...";
    }
}
```

#### Tính trừu tượng

Là việc loại bỏ những chi tiết phức tạp, không cần thiết của đối tượng và chỉ tập trung vào những đặc điểm quan trọng nhất.

```php
abstract class CanhCua
{
    // Cửa nào thì cũng phải có hành động Mở và Đóng
    abstract public function mo();
    abstract public function dong();
}

class CuaCuon extends CanhCua
{
    public function mo()
    {
        return "Điều khiển từ xa để kéo cửa lên";
    }
    public function dong()
    {
        return "Nhấn nút để hạ cửa xuống";
    }
}
```

### Phân biệt Abtract và Interface

| Đặc điểm    | Abtract Class                             | Interface                                                      |
| ----------- | ----------------------------------------- | -------------------------------------------------------------- |
| Bản chất    | Là 1 nhóm có liên quan mật thiết đến nhau | Là một hành động phải tuân thủ mặc dù không liên quan đến nhau |
| Phương thức | Có thể có hàm đã xử lý hoặc hàm trống     | Chỉ khai báo tên hàm, không được viết code xử lý               |
| Thuộc tính  | Có thể chứa biến (property)               | Chỉ có thể chứa hằng số                                        |
| Kế thừa     | 1 class chỉ được kế thừa 1 abtract class  | 1 class có thể thực thi (implements) nhiều interface           |
| Access      | Có thể sử dụng publuc, protected, private | Tất cả phải là public                                          |

- Ví dụ minh họa

```php
abstract class Animal
{
    public $name;

    // Hàm bình thường, các con dùng chung
    public function sleep()
    {
        echo "Đang ngủ...";
    }

    // Hàm bắt buộc các con phải tự định nghĩa
    abstract public function makeSound();
}

class Dog extends Animal
{
    public function makeSound()
    {
        echo "Gâu gâu";
    }
}
```

```php
interface Flyable
{
    public function fly();
}

interface Swimable
{
    public function swim();
}

// Một Class có thể vừa biết bay, vừa biết bơi
class Duck implements Flyable, Swimable
{
    public function fly()
    {
        echo "Vịt đang bay thấp";
    }
    public function swim()
    {
        echo "Vịt đang bơi";
    }
}
```
