## 🎯 Mục tiêu khóa học

- Hiểu PHP là gì và các ứng dụng phổ biến
- Setup được môi trường chạy PHP trên máy cá nhân
- Nắm cú pháp cơ bản: syntax, variable, constant
- Làm việc được với data types, string, array
- Viết được điều kiện (if/switch), vòng lặp (for/foreach/while)
- Viết và sử dụng function (built-in + user-defined)

## 👥 Đối tượng

- Thực tập sinh / Fresher cần nền tảng PHP
- Đã biết HTML/CSS cơ bản là lợi thế

## ✅ Yêu cầu trước khi học

- Cài sẵn XAMPP/Laragon (Windows) hoặc PHP + web server (macOS/Linux)
- Editor: VS Code (khuyến nghị) + PHP Intelephense
