## Yêu cầu

- Tạo file riêng cho từng bài (ví dụ: `bai_01.php`, `bai_02.php`…)
- Commit lên Git (nếu team có quy ước) hoặc nộp link/zip theo hướng dẫn trainer
- Mỗi bài cần có: input (hard-code hoặc form), xử lý, output rõ ràng

## Bài 01 — Kiểm tra số nguyên tố

- Viết function `isPrime($n)` trả về `true/false`
- Test với các giá trị: 1, 2, 3, 4, 9, 11, 15

## Bài 02 — Kiểm tra năm nhuận

- Viết function `isLeapYear($year)` theo quy tắc:
  - Chia hết cho 400 → nhuận
  - Chia hết cho 4 nhưng không chia hết cho 100 → nhuận
  - Còn lại → không nhuận

## Bài 03 — Sort mảng

- Có mảng `$nums = [5, 2, 9, 1]`
- Sort tăng dần và giảm dần
- In kết quả trước/sau khi sort

## Bài 04 — Xử lý string

- Nhập chuỗi bất kỳ `$text`
- In ra:
  - độ dài
  - chữ hoa / chữ thường
  - số từ trong chuỗi

## Bài 05 — While vs Do-while

- Tạo 2 ví dụ nhỏ minh họa sự khác nhau giữa `while` và `do...while`
