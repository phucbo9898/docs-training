## 🎯 Mục tiêu

- Hiểu các kiểu dữ liệu phổ biến trong PHP
- Thao tác cơ bản với string
- Khai báo và sử dụng array (mảng)

## 1) Data types phổ biến

| Type    | Ví dụ      | Ghi chú          |
| ------- | ---------- | ---------------- |
| String  | "Hello"    | Chuỗi ký tự      |
| Integer | 10         | Số nguyên        |
| Float   | 10.5       | Số thực          |
| Boolean | true       | Đúng/Sai         |
| Array   | \[1, 2, 3] | Mảng             |
| NULL    | null       | Không có giá trị |

## 2) String

### Nối chuỗi

```php
<?php
$name = "Phuc";
echo "Hello " . $name;
```

### Một số hàm hay dùng

```php
<?php
strlen("Hello");                // độ dài
strtoupper("hello");            // HELLO
trim("  hello  ");              // "hello"
sprintf("Hello %s", "Phuc");    // format
```

## 3) Array

### 3.1 Mảng tuần tự (indexed array)

```php
<?php
$colors = ["red", "blue"];
echo $colors[0]; // red
```

### 3.2 Mảng kết hợp (associative array)

```php
<?php
$user = [
	"name" => "Phuc",
	"age" => 20,
];
echo $user["name"];
```

### 3.3 Mảng đa chiều (multidimensional array)

```php
<?php
$data = [
	"colors" => ["red", "blue"],
	"users" => [
		["name" => "A"],
		["name" => "B"],
	],
];
```

### Một số hàm array hay dùng

```php
<?php
$nums = [3, 1, 2];
sort($nums);           // [1,2,3]
array_push($nums, 4);  // thêm phần tử
```
