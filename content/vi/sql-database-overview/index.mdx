## 🎯 Mục tiêu khóa học

- Hiểu bản chất **Database / DBMS** và mô hình dữ liệu quan hệ
- Thiết kế bảng cơ bản: PK/FK, ràng buộc, kiểu dữ liệu
- Nắm SQL từ cơ bản → nâng cao: CRUD, lọc/sắp xếp, hàm, GROUP BY
- Làm việc được với **JOIN**, **Subquery**
- Viết query giải quyết bài toán thực tế và tối ưu cơ bản

## ✅ Yêu cầu môi trường

- MySQL / MariaDB (khuyến nghị)
- Tool: DBeaver / MySQL Workbench / Navicat / HeidiSQL

## 🧱 Kiến thức nền tảng (tóm tắt)

- **Database**: nơi lưu trữ dữ liệu có cấu trúc
- **DBMS**: phần mềm quản trị CSDL (MySQL, PostgreSQL, SQL Server…)
- **SQL**: ngôn ngữ truy vấn và thao tác dữ liệu

Phân loại câu lệnh SQL:

- **DDL**: CREATE / ALTER / DROP (định nghĩa cấu trúc)
- **DML**: SELECT / INSERT / UPDATE / DELETE (thao tác dữ liệu)
- **DCL**: GRANT / REVOKE (phân quyền)
- **TCL** (tham khảo): COMMIT / ROLLBACK (transaction)
