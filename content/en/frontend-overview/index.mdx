## 🎯 Course Objectives

- Learn the HTML fundamentals for building a web page's structure
- Know CSS for layout + styling, and use Bootstrap to build UI quickly
- Learn the basics of JavaScript: DOM, events, functions, arrays/objects
- Know jQuery for quick DOM manipulation and Ajax
- Call APIs and render data in the UI (AJAX / fetch)
- Understand how Frontend ↔ Backend fit together (form submit, validate, call API)

## 👥 Target Audience

- Interns / Freshers who are just starting with Frontend
- Have a personal computer and can run a project locally on their own

## ✅ Prerequisites

- Editor: VS Code
- Browser: Chrome/Edge (recommended)
- Knowing basic Git is an advantage

## 📝 Practice Conventions

- Create a separate folder for each lesson (for example: `lesson-01-html/`, `lesson-02-css/`…)
- Always split files: `index.html`, `style.css`, `app.js` (don't write everything inline)
- Name classes using BEM or your team's convention (prefer clear, meaningful names)
