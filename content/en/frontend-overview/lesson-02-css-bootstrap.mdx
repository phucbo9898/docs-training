## 🎯 Objectives

- Understand what CSS is used for
- Know selectors + the box model + basic layout
- Know how to organize CSS files
- Use Bootstrap to build layouts/UI quickly

## 1) What is CSS?

CSS is used to **style the interface** of HTML. CSS files usually have the `.css` extension.

## 2) CSS Structure

```css
selector {
	property: value;
}
```

## 3) Basic Selectors

```css
/* tag */
p { color: red; }

/* class */
.box { background: blue; }

/* id */
#header { font-size: 20px; }
```

## 4) Ways to Add CSS

### External (recommended)

```html
<link rel="stylesheet" href="style.css" />
```

### Internal

```html
<style>
	p { color: red; }
</style>
```

### Inline (use sparingly)

```html
<p style="color: red;">Hello</p>
```

## 5) Box Model (Core)

- margin, border, padding, content

## 6) Quick Layout with Flexbox (Recommended)

```css
.container {
	display: flex;
	gap: 12px;
}
```

## 7) Bootstrap (Introduction)

Bootstrap is a CSS framework that helps you build UI quickly with a grid system + utility classes + components.

### Installation (CDN)

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet" />
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

### Basic Grid

```html
<div class="container">
	<div class="row">
		<div class="col-12 col-md-6">Left</div>
		<div class="col-12 col-md-6">Right</div>
	</div>
</div>
```

### Component Example (Button)

```html
<button class="btn btn-primary">Save</button>
```
