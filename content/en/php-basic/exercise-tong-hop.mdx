## Requirements

- Create a separate file for each problem (for example: `bai_01.php`, `bai_02.php`…)
- Commit to Git (if your team has a convention) or submit a link/zip as instructed by your trainer
- Each problem needs: input (hard-coded or a form), processing, and clear output

## Problem 01 — Check for a prime number

- Write a function `isPrime($n)` that returns `true/false`
- Test with these values: 1, 2, 3, 4, 9, 11, 15

## Problem 02 — Check for a leap year

- Write a function `isLeapYear($year)` following these rules:
  - Divisible by 400 → leap year
  - Divisible by 4 but not divisible by 100 → leap year
  - Otherwise → not a leap year

## Problem 03 — Sort an array

- Given the array `$nums = [5, 2, 9, 1]`
- Sort it in ascending and descending order
- Print the result before/after sorting

## Problem 04 — String handling

- Enter any string `$text`
- Print out:
  - the length
  - uppercase / lowercase versions
  - the number of words in the string

## Problem 05 — While vs Do-while

- Create 2 small examples that show the difference between `while` and `do...while`
