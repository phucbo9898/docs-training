## 🎯 Objectives

- Write `if / else / elseif` conditions
- Know how to use `switch`
- Get familiar with shorthand operators (ternary, null coalescing)

## 1) if / else / elseif

```php
<?php
$age = 20;

if ($age >= 18) {
	echo "Adult";
} else {
	echo "Child";
}
```

## 2) switch

```php
<?php
$role = "admin";

switch ($role) {
	case "admin":
		echo "Admin";
		break;
	case "user":
		echo "User";
		break;
	default:
		echo "Guest";
}
```

## 3) Ternary operator

```php
<?php
$age = 20;
$result = ($age >= 18) ? "Adult" : "Child";
```

## 4) Null coalescing (??)

```php
<?php
$name = $_GET["name"] ?? "Guest";
```
