## 🎯 Objectives

- Understand when to use `for`, `foreach`, `while`, `do...while`
- Iterate over an array and print its data

## 1) for

```php
<?php
for ($i = 0; $i < 5; $i++) {
	echo $i;
}
```

## 2) foreach (iterating over an array)

```php
<?php
$colors = ["red", "blue", "green"];

foreach ($colors as $color) {
	echo $color;
}
```

## 3) while

```php
<?php
$i = 0;

while ($i < 5) {
	$i++;
}
```

## 4) do...while

```php
<?php
$i = 0;

do {
	$i++;
} while ($i < 5);
```
