## 🎯 Course Objectives

- Understand what PHP is and where it is commonly used
- Set up a PHP environment on your own computer
- Learn the basics: syntax, variables, constants
- Work with data types, strings and arrays
- Write conditions (if/switch) and loops (for/foreach/while)
- Write and use functions (built-in + user-defined)

## 👥 Target Audience

- Interns / Freshers who need a PHP foundation
- Knowing basic HTML/CSS is an advantage

## ✅ Prerequisites

- XAMPP/Laragon installed (Windows) or PHP + a web server (macOS/Linux)
- Editor: VS Code (recommended) + PHP Intelephense
