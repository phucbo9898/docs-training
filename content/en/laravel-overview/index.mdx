## 🎯 1. Course Objectives

- Understand the Laravel framework and how it works with the MVC pattern
- Learn the structure of a Laravel project
- Know how to work with Routing, Middleware and Models
- Work with the database using Migrations, Seeders and Eloquent ORM
- Be able to build a basic API/Web app with Laravel

## 🗺️ 2. Learning Path

- Understand what Laravel is
- Set up the environment & run a project
- Understand the project structure
- Work with HTTP (Controller, Middleware, Request)
- Work with the database (Migration, Seeder)
- Query data with Eloquent ORM

## 🛠️ 3. Environment Requirements (Requirements)

- PHP >= 8.2
- Composer
- XAMPP / Laragon
- MySQL
- VS Code / PHPStorm

## 📌 4. Training Rules

- Read + practice every lesson
- Each lesson is followed by a small exercise
- Don't copy code; understand the logic
- Review your code with a mentor

## 🎯 5. Outcomes After Training

- Be able to build a CRUD API with Laravel on your own
- Understand the flow request → controller → model → response
