## 🎯 Course Objectives

- Understand the nature of a **Database / DBMS** and the relational data model
- Design basic tables: PK/FK, constraints, data types
- Learn SQL from basic → advanced: CRUD, filtering/sorting, functions, GROUP BY
- Work with **JOIN** and **Subquery**
- Write queries that solve real-world problems, with basic optimization

## ✅ Environment Requirements

- MySQL / MariaDB (recommended)
- Tools: DBeaver / MySQL Workbench / Navicat / HeidiSQL

## 🧱 Foundations (Summary)

- **Database**: a place that stores structured data
- **DBMS**: database management software (MySQL, PostgreSQL, SQL Server…)
- **SQL**: a language for querying and manipulating data

Categories of SQL statements:

- **DDL**: CREATE / ALTER / DROP (define structure)
- **DML**: SELECT / INSERT / UPDATE / DELETE (manipulate data)
- **DCL**: GRANT / REVOKE (permissions)
- **TCL** (for reference): COMMIT / ROLLBACK (transactions)
